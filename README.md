# Computer Networks

A collection of code implementations for various networking concepts and protocols.

## Repository Contents

### Socket Programming
- **socket_calc**: A calculator application using socket programming
- **socket_file**: File transfer implementation using sockets
- **socket_hello**: Basic socket program demonstrating client-server communication
- **udp_socket**: UDP socket implementation examples

### Networking Tools & Protocols
- **DNS_lookup.py**: DNS lookup tool implementation
- **class_given_IP.py**: IP address class identification utility

### Error Detection & Coding
- **hamming.py**: Hamming code implementation for error detection and correction
- **selective_repeat.py**: Selective Repeat ARQ protocol implementation
- **go_back.py**: Go-Back-N ARQ protocol implementation
- **crc.py**: Cyclic Redundancy Check implementation

## Getting Started

To run any of the programs in this repository:

1. Clone the repository:
   ```
   git clone https://github.com/sg6724/Computer-Networks.git
   ```

2. Navigate to the desired program directory:
   ```
   cd Computer-Networks
   ```

3. Run the Python scripts:
   ```
   python [script_name].py
   ```

## Prerequisites

- Python 3.x
- Basic understanding of networking concepts
